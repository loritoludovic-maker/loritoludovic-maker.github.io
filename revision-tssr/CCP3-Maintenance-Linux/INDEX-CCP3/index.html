    📚 CCP3 - MAINTENANCE LINUX - INDEX¶

    Coefficient : 10%
    Temps de révision estimé : 5-6h
    Contenu : 50 QCM + 20 Questions ouvertes + 1 MSP pratique

    🎯 Objectifs du CCP3¶

    Maîtriser l'administration système Linux : - Navigation et gestion du système de fichiers - Gestion des utilisateurs et permissions - Gestion des processus et services - Configuration réseau Linux - Analyse des logs - Gestion des paquets - Configuration de services (Apache, SSH, NFS, Samba, Cron)

    💡 CONSEILS SPÉCIFIQUES LINUX¶

    Commandes à connaître PAR CŒUR¶

    Navigation : 

    cd, ls, pwd, find, locate, which, whereis

    Fichiers : 

    cat, less, more, head, tail, grep, sed, awk
cp, mv, rm, mkdir, rmdir, touch

    Permissions : 

    chmod, chown, chgrp, umask
chmod 755, chmod 644, chmod 777

    Utilisateurs : 

    useradd, usermod, userdel, passwd
su, sudo, id, whoami, who, w

    Processus : 

    ps aux, top, htop, kill, killall, pkill
nice, renice, bg, fg, jobs, nohup

    Services : 

    systemctl start/stop/restart/status nom_service
systemctl enable/disable nom_service
systemctl list-units --type=service

    Réseau : 

    ip addr, ip route, ip link
ping, traceroute, netstat, ss, nmap
iptables -L, firewall-cmd

    Logs : 

    journalctl -u nom_service
journalctl --since "2023-01-01"
tail -f /var/log/syslog

    Pratique recommandée¶

    Installe une VM Linux : - Ubuntu Server 22.04 LTS (plus facile) - Rocky Linux 9 (équivalent RHEL) - Debian 12 (stable)

    Entraîne-toi sur : - Créer des utilisateurs et groupes - Gérer les permissions (chmod/chown) - Installer et configurer Apache2 - Configurer SSH (désactiver root, changer port) - Créer des tâches cron - Analyser les logs avec journalctl
