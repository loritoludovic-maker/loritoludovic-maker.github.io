    🎯 Les 9 CCPs (Certificats de Compétences Professionnelles)¶

    🔴 Priorité absolue (60% du coefficient)¶

    CCP Thème Coefficient Temps révision
    CCP6 Scripts et Automatisation 25% 5-6h
    CCP2 Windows / Active Directory 20% 6-7h
    CCP5 Virtualisation (VMware) 15% 4-5h

    🟡 Priorité élevée (25% du coefficient)¶

    CCP Thème Coefficient Temps révision
    CCP3 Maintenance Linux 10% 5-6h
    CCP1 Support Utilisateur 10% 4-5h
    CCP8 Sauvegardes & Restaurations 5% 3-4h

    🟢 Priorité moyenne (15% du coefficient)¶

    CCP Thème Coefficient Temps révision
    CCP4 Services Réseau 10% 6-7h
    CCP7 Sécurisation Internet 10% 3-4h
    CCP9 Déploiement Postes 10% 3-4h

    📊 Contenu disponible¶

    Chaque CCP contient :¶

    • 📖 1 fiche de révision complète
    • 📝 1 QCM avec évaluation et correction séparées
    • 📋 1 série de questions ouvertes avec évaluation et correction

    En bonus :¶

    • ✅ 2 examens blancs complets (3h30 chacun) avec corrections détaillées
    • ✅ 1 simulation orale complète (3 parties)
    • ✅ Planning de révision sur 5 jours
    • ✅ Guide méthodologique complet

    Statistiques :¶

    • ~285 questions QCM au total
    • ~119 questions ouvertes détaillées
    • ~50 heures de contenu de révision
    • 41 fichiers de ressources

    💡 Méthodologie recommandée¶

    Pour chaque CCP :¶

    1. 📖 Lire la fiche de révision (30-60 min)
    2. Prendre des notes

    3. Surligner les points importants

    4. 📝 Faire le QCM en conditions réelles (sans la correction)

    5. Chronométrer

    6. Noter ses réponses

    7. ✅ Corriger avec la correction

    8. Comprendre ses erreurs

    9. Compléter ses notes

    10. 📋 Traiter les questions ouvertes

    11. Essayer de répondre seul
    12. Comparer avec les corrections

    13. Approfondir si nécessaire

    14. 🔄 Réviser les points faibles

    15. Refaire les questions ratées
    16. Consulter d'autres ressources si besoin

    📅 Organisation de la révision¶

    Option 1 : Révision intensive (5 jours)¶

    Suis le PLANNING-REVISION-5-JOURS.md - Jour 1 : Linux + Support - Jour 2 : Sauvegardes + Réseau + Windows - Jour 3 : Virtualisation + Scripts + Sécurité - Jour 4 : Examen Blanc 1 + Révisions - Jour 5 : Examen Blanc 2 + Simulation orale

    Option 2 : Révision par priorité¶

    1. Semaine 1 : CCPs prioritaires (2, 5, 6)
    2. Semaine 2 : CCPs complémentaires (1, 3, 8)
    3. Semaine 3 : CCPs restants (4, 7, 9)
    4. Semaine 4 : Examens blancs + Simulation orale

    Option 3 : Révision ciblée¶

    Concentre-toi sur tes points faibles identifiés lors des QCM

    🎯 Conseils pour réussir¶

    Pendant la révision :¶

    • ✅ Fais tous les QCM sans regarder les réponses
    • ✅ Chronomètre-toi pour t'habituer à la pression
    • ✅ Note tes scores dans le fichier de suivi
    • ✅ Identifie tes lacunes et révise-les en priorité
    • ✅ Refais les questions ratées quelques jours après

    Le jour de l'examen :¶

    • 🎯 Gère ton temps : Ne reste pas bloqué sur une question
    • 🎯 Lis bien les consignes : Souvent des indices dans l'énoncé
    • 🎯 Commence par les questions faciles pour prendre confiance
    • 🎯 Reviens sur les questions difficiles à la fin
    • 🎯 Vérifie tes réponses si tu as du temps

    📚 Ressources complémentaires¶

    Documentation officielle :¶

    • Microsoft Learn : Windows Server, Active Directory, PowerShell
    • VMware Docs : vSphere, vMotion, HA/DRS
    • Linux man pages : Documentation complète des commandes
    • Cisco IOS : Configuration switch/routeur

    Outils pratiques :¶

    • Subnet Calculator : Calculs de sous-réseaux
    • RegEx Tester : Tests d'expressions régulières
    • PowerShell ISE : Tests de scripts PowerShell
    • VM VirtualBox/VMware : Pratique sur environnement virtuel

    🤝 Contribution¶

    Ce projet de révision est personnel mais partagé pour aider d'autres candidats TSSR.

    Si tu trouves une erreur :¶

    1. Note-la dans tes révisions
    2. Vérifie avec la documentation officielle
    3. (Optionnel) Crée une issue GitHub si le projet est public

    Bonnes pratiques :¶

    • Complète les fiches avec tes propres notes
    • Ajoute des exemples pratiques issus de ton expérience
    • Partage avec d'autres candidats TSSR
