    🎫 QCM SUPPORT UTILISATEUR & ITIL - 40 QUESTIONS¶

    GLPI, ITIL v3/v4, Helpdesk, Gestion de tickets¶

    Pour l'examen : Support N1/N2/N3, ITIL (incident/problème/changement), SLA/OLA, cycle de vie ticket

    📋 PARTIE 1 : SUPPORT UTILISATEUR & HELPDESK (Questions 1-15)¶

    Question 1¶

    Quel est le rôle principal d'un technicien support N1 ? - [ ] A) Résoudre les incidents complexes nécessitant une expertise approfondie - [ ] B) Qualifier, enregistrer et résoudre les incidents simples - [ ] C) Développer des correctifs pour les bugs applicatifs - [ ] D) Gérer les projets de déploiement informatique

    Question 2¶

    Un utilisateur signale qu'il ne peut pas accéder à son dossier réseau. Quelle est la première action à effectuer ? - [ ] A) Réinstaller Windows sur le poste - [ ] B) Vérifier les droits NTFS et l'appartenance aux groupes - [ ] C) Remplacer le câble réseau - [ ] D) Formater le serveur de fichiers

    Question 3¶

    Dans GLPI, quel est le statut d'un ticket qui vient d'être créé par un utilisateur ? - [ ] A) En cours (attribué) - [ ] B) Nouveau - [ ] C) En attente - [ ] D) Planifié

    Question 4¶

    Quelle est la différence entre urgence et impact d'un incident ? - [ ] A) L'urgence = nombre d'utilisateurs, l'impact = délai de résolution - [ ] B) L'urgence = délai de traitement souhaité, l'impact = étendue des conséquences - [ ] C) Ce sont deux termes synonymes - [ ] D) L'urgence concerne les tickets VIP uniquement

    Question 5¶

    Comment calcule-t-on la priorité d'un ticket dans la plupart des outils de ticketing ? - [ ] A) Priorité = Urgence + Impact - [ ] B) Priorité = Urgence × Impact (matrice) - [ ] C) Priorité = Nombre d'utilisateurs affectés - [ ] D) Priorité = Ancienneté du ticket

    Question 6¶

    Un utilisateur dit : "Mon ordinateur est lent". Quelle technique de questionnement utiliser ? - [ ] A) Questions fermées uniquement (oui/non) - [ ] B) Questions ouvertes (QQOQCCP : Qui, Quoi, Où, Quand, Comment, Combien, Pourquoi) - [ ] C) Ne pas poser de questions, agir immédiatement - [ ] D) Demander à l'utilisateur de trouver la solution lui-même

    Question 7¶

    Que signifie escalade verticale (escalade hiérarchique) ? - [ ] A) Passer le ticket à un collègue du même niveau - [ ] B) Passer le ticket à un niveau supérieur (N1 → N2 → N3) - [ ] C) Fermer le ticket sans résolution - [ ] D) Diminuer la priorité du ticket

    Question 8¶

    Dans une base de connaissances (knowledge base), que doit contenir un article de résolution ? - [ ] A) Uniquement le symptôme - [ ] B) Symptôme + Cause + Solution + Mots-clés - [ ] C) Seulement la solution - [ ] D) Les informations confidentielles

    Question 9¶

    Un utilisateur est mécontent et agressif au téléphone. Quelle est la meilleure attitude ? - [ ] A) Raccrocher immédiatement - [ ] B) Rester calme, écouter activement, reformuler, empathie - [ ] C) Être agressif en retour - [ ] D) Transférer systématiquement au manager

    Question 10¶

    Que signifie SLA (Service Level Agreement) ? - [ ] A) Accord de niveau de service (contrat avec engagement de délais) - [ ] B) Standard Linux Administration - [ ] C) Software License Agreement - [ ] D) Support Level Allocation

    Question 11¶

    Un SLA indique "P1 : résolution en 4 heures". C'est un délai de : - [ ] A) Résolution garantie (le problème DOIT être résolu en 4h) - [ ] B) Prise en compte (accusé réception en 4h) - [ ] C) Objectif de résolution (cible, pas garantie absolue) - [ ] D) Attente maximale avant fermeture automatique

    Question 12¶

    Quelle est la différence entre SLA et OLA ? - [ ] A) SLA = externe (client), OLA = interne (entre équipes IT) - [ ] B) SLA et OLA sont identiques - [ ] C) SLA = gratuit, OLA = payant - [ ] D) OLA n'existe pas en support

    Question 13¶

    Un ticket est en statut "En attente". Cela signifie généralement : - [ ] A) Le ticket est résolu - [ ] B) On attend une action de l'utilisateur ou d'un tiers - [ ] C) Le ticket est annulé - [ ] D) Le technicien a abandonné

    Question 14¶

    Quel indicateur mesure la satisfaction utilisateur ? - [ ] A) MTBF (Mean Time Between Failures) - [ ] B) MTTR (Mean Time To Repair) - [ ] C) CSAT (Customer Satisfaction Score) ou NPS - [ ] D) RPO (Recovery Point Objective)

    Question 15¶

    Pourquoi catégoriser les tickets (matériel, logiciel, réseau, etc.) ? - [ ] A) Pour faire joli dans l'outil - [ ] B) Pour générer des statistiques, identifier les tendances, optimiser les ressources - [ ] C) C'est obligatoire légalement - [ ] D) Pour compliquer le travail

    🔧 PARTIE 2 : ITIL v3 FONDAMENTAUX (Questions 16-25)¶

    Question 16¶

    Que signifie ITIL ? - [ ] A) Information Technology Infrastructure Library - [ ] B) International Technical IT License - [ ] C) Integrated Tools for IT Learning - [ ] D) Internet Technology Implementation Level

    Question 17¶

    Dans ITIL, quelle est la différence entre un incident et un problème ? - [ ] A) Incident = panne réelle, Problème = panne potentielle - [ ] B) Incident = interruption/dégradation service, Problème = cause inconnue d'incidents - [ ] C) Ce sont deux mots pour la même chose - [ ] D) Problème = plusieurs incidents simultanés

    Question 18¶

    Un utilisateur ne peut pas imprimer. C'est un : - [ ] A) Incident - [ ] B) Problème - [ ] C) Changement - [ ] D) Événement

    Question 19¶

    5 utilisateurs du même service ne peuvent pas imprimer sur la même imprimante. On découvre que le driver est corrompu. La cause racine (driver corrompu) est : - [ ] A) Un incident - [ ] B) Un problème - [ ] C) Une demande de service - [ ] D) Un changement

    Question 20¶

    Quelle est la priorité absolue de la gestion des incidents ? - [ ] A) Trouver la cause racine - [ ] B) Restaurer le service le plus rapidement possible (contournement acceptable) - [ ] C) Punir le responsable - [ ] D) Documenter parfaitement

    Question 21¶

    Quelle est la priorité de la gestion des problèmes ? - [ ] A) Restaurer le service rapidement - [ ] B) Identifier et éliminer la cause racine pour éviter la récurrence - [ ] C) Fermer le plus de tickets possible - [ ] D) Créer des workarounds

    Question 22¶

    Qu'est-ce qu'un workaround (solution de contournement) ? - [ ] A) La cause racine d'un incident - [ ] B) Une solution temporaire qui permet de restaurer le service sans corriger la cause - [ ] C) Un changement planifié - [ ] D) Un incident grave

    Question 23¶

    Qu'est-ce qu'un changement (change) dans ITIL ? - [ ] A) Toute modification de l'infrastructure IT susceptible d'impacter les services - [ ] B) Un incident résolu - [ ] C) Un problème identifié - [ ] D) Une demande utilisateur

    Question 24¶

    Quel est le rôle du CAB (Change Advisory Board) ? - [ ] A) Résoudre les incidents - [ ] B) Évaluer, approuver ou rejeter les changements - [ ] C) Créer les tickets - [ ] D) Former les utilisateurs

    Question 25¶

    Quels sont les 3 types de changements ITIL ? - [ ] A) Standard, Normal (planifié), Urgent (emergency) - [ ] B) Petit, Moyen, Grand - [ ] C) Matériel, Logiciel, Réseau - [ ] D) Approuvé, Refusé, En attente

    🆕 PARTIE 3 : ITIL 4 & ÉVOLUTIONS (Questions 26-35)¶

    Question 26¶

    ITIL 4 remplace les 5 phases du cycle de vie (v3) par : - [ ] A) 7 phases de développement - [ ] B) La chaîne de valeur des services (Service Value Chain - SVC) - [ ] C) 10 processus obligatoires - [ ] D) 3 niveaux de support

    Question 27¶

    ITIL 4 introduit les 34 pratiques de gestion. Lesquelles remplacent "Gestion des incidents" et "Gestion des problèmes" d'ITIL v3 ? - [ ] A) Elles n'existent plus - [ ] B) Incident Management et Problem Management (mêmes noms, évoluées) - [ ] C) Service Desk Management - [ ] D) Continuous Improvement

    Question 28¶

    Dans ITIL 4, que signifie SVS (Service Value System) ? - [ ] A) Le système complet de création de valeur (inclut SVC, pratiques, principes directeurs) - [ ] B) Un outil de ticketing - [ ] C) Un type de sauvegarde - [ ] D) Un indicateur de performance

    Question 29¶

    Combien y a-t-il de principes directeurs (guiding principles) dans ITIL 4 ? - [ ] A) 4 - [ ] B) 7 - [ ] C) 10 - [ ] D) 12

    Question 30¶

    Quel principe ITIL 4 signifie "Commencer là où vous êtes" ? - [ ] A) Ne jamais changer - [ ] B) Analyser l'existant avant de tout reconstruire, réutiliser ce qui fonctionne - [ ] C) Toujours repartir de zéro - [ ] D) Rester sur les anciennes versions

    Question 31¶

    Le principe "Focus sur la valeur" signifie : - [ ] A) Maximiser les profits - [ ] B) Toutes les activités doivent contribuer à créer de la valeur pour le client - [ ] C) Réduire les coûts uniquement - [ ] D) Facturer plus cher

    Question 32¶

    Dans la chaîne de valeur des services (SVC) ITIL 4, quelles sont les 6 activités ? - [ ] A) Planifier, Construire, Exécuter, Tester, Déployer, Fermer - [ ] B) Plan, Improve, Engage, Design & Transition, Obtain/Build, Deliver & Support - [ ] C) Incident, Problème, Changement, Release, Configuration, Capacité - [ ] D) Support N1, N2, N3, Manager, Directeur, Client

    Question 33¶

    ITIL 4 met l'accent sur l'approche Agile et DevOps. Que signifie DevOps ? - [ ] A) Développement sans opérations - [ ] B) Collaboration Dev (développement) + Ops (opérations) pour livrer plus vite - [ ] C) Un outil de ticketing - [ ] D) Un certificat ITIL

    Question 34¶

    Quelle pratique ITIL 4 gère la base de connaissances ? - [ ] A) Knowledge Management - [ ] B) Information Security Management - [ ] C) Service Desk - [ ] D) Incident Management

    Question 35¶

    Dans ITIL 4, qu'est-ce que le continual improvement (amélioration continue) ? - [ ] A) Un projet ponctuel - [ ] B) Une pratique permanente d'optimisation itérative (Kaizen) - [ ] C) Un rôle spécifique - [ ] D) Un logiciel

    🛠️ PARTIE 4 : PRATIQUES & OUTILS (Questions 36-40)¶

    Question 36¶

    Quel outil open-source est couramment utilisé pour la gestion de tickets IT ? - [ ] A) GLPI - [ ] B) Microsoft Word - [ ] C) Adobe Photoshop - [ ] D) VLC Media Player

    Question 37¶

    Dans GLPI, que permet la fonction "Ticket parent/enfant" ? - [ ] A) Gérer les relations familiales des utilisateurs - [ ] B) Lier des tickets (incident global → sous-incidents) - [ ] C) Bloquer la création de tickets - [ ] D) Supprimer automatiquement les tickets

    Question 38¶

    Qu'est-ce qu'un Self-Service Portal ? - [ ] A) Un portail où les utilisateurs peuvent créer des tickets, consulter la KB, suivre leurs demandes - [ ] B) Un service de restauration - [ ] C) Un outil de piratage - [ ] D) Un type de firewall

    Question 39¶

    Pour mesurer la performance du support, quel indicateur mesure le temps moyen de résolution ? - [ ] A) MTTR (Mean Time To Resolve) - [ ] B) MTBF (Mean Time Between Failures) - [ ] C) RTO (Recovery Time Objective) - [ ] D) SLA (Service Level Agreement)

    Question 40¶

    Dans un contexte ITIL, qu'est-ce que la CMDB (Configuration Management Database) ? - [ ] A) Une base de données des tickets - [ ] B) Une base de données des éléments de configuration (CI) et leurs relations - [ ] C) Un outil de monitoring réseau - [ ] D) Un système de sauvegarde
